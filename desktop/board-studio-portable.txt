Board Studio · 展板工作台（免安装版）

双击 BoardStudio.exe 启动，不需要安装或启动网页服务。

1. 工作台顶部“生图模型 · 自动读取”沿用现有 API，读取模型列表；可下拉切换。
2. 填写主题与要求、添加参考图，点击“① 生成完整效果图”。再次生成会新增候选展板。
3. 选中满意的图片，点击“② 拆分元素与文字”。双击进入分组或在图层列表选元素；文字可改内容和字体，图片可填写要求后点击“③ 重新生成所选元素”。
4. 工作台导出 PNG/JPG 写入 300 ppi；A3 竖版为 3508 × 4961 px。
5. 用文件菜单保存可编辑源文件。

生图需要 OpenAI Images 接口。服务商不提供模型列表时才在“高级设置”手填 ID。透明花字还需支持 transparent PNG，背景补全使用多图 image[]。生图、去字、分割和补全按服务商计费。拆分文字需要支持看图的视觉模型。工作台按钮直接调用 API；聊天生图/拆分工具仅适用于直接 API 聊天，尚未接入 ACP。

拆分参考 Codex Canvas 方法（许可证见 licenses）。图片成为可单独移动、缩放和重生成的透明图层，内部仍是像素；文字重建成真实文字层。原图保留隐藏，可撤销拆分。去字和分割可能改变细节，OCR 不确定文字标为“待校对”，需检查后投稿。导出分辨率不增加低清素材细节。

更新时保存作品并关闭程序，再替换对应程序文件。设置和缓存保存在 Windows 用户数据目录。需要系统已有 Microsoft Edge WebView2 运行时。
