Board Studio · 展板工作台（免安装版）

双击 BoardStudio.exe 启动，不需要安装或启动网页服务。

1. 新建/选择 A3 画板，填写主题与要求，添加参考图。
2. 点击“分析参考”“先做主视觉”“透明标题花字”或“制作整板”。
3. 在下方 AI 对话继续修改；生成素材、标题花字、正文保持独立图层。
4. 工作台导出 PNG/JPG 写入 300 ppi；A3 竖版为 3508 × 4961 px。
5. 用文件菜单保存可编辑源文件。

“生图 API 设置”填写服务商提供的图像模型 ID，选择已有 API 连接。要求支持 OpenAI Images 接口，透明花字还需支持 transparent PNG。生图按服务商计费。本版生成工具用于直接 API 设计聊天；Codex ACP 支持看图，尚未接入此应用侧生图工具。

图片内部仍是像素，需要通过改图处理；正文用本地字体的真实文字层。导出分辨率不增加低清素材的实际细节。A3 画板之外的自定义尺寸保持实际像素量。

更新时保存作品并关闭程序，再替换对应程序文件。设置和缓存保存在 Windows 用户数据目录。需要系统已有 Microsoft Edge WebView2 运行时。
