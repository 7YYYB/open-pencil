Board Studio · 展板工作台（免安装版）

双击 BoardStudio.exe 启动，不需要安装或启动网页服务。

1. 新建设计或打开文档，在右侧「创作」输入「做一张 A3 竖版文创 IP 展板……」，参考图可直接粘贴或拖进对话。
2. 生成方案会出现在画布和对话。可以点「再做一版」或对满意的方案点「拆分图层」。
3. 选中素材后点画布上的「描述改图」，或在对话里告诉 AI 要怎么改。双击文字改内容，右侧「属性」里改字体和粗细。
4. 选中展板外框，点「导出展板」保存 300 ppi PNG。A3 竖版为 3508 × 4961 px。
5. 用文件菜单保存可编辑源文件。

「设置 → 模型」管理自定义 API、对话模型和视觉模型。「设置 → 图像生成」沿用已有 API，可自动选择返回的生图模型，也可手填自定义模型 ID。生图需要 OpenAI Images 接口。透明素材需要接口支持透明 PNG，背景补全使用多图 image[]。生图、去字、分割和补全按服务商计费。拆分文字需要视觉模型。

拆分参考 Codex Canvas 方法（许可证见 licenses）。图片成为可单独移动、缩放和重生成的透明图层，内部仍是像素；文字重建成真实文字层。原图保留隐藏，可撤销拆分。去字和分割可能改变细节，OCR 不确定文字标为“待校对”，需检查后投稿。导出分辨率不增加低清素材细节。

更新时保存作品并关闭程序，再替换对应程序文件。设置和缓存保存在 Windows 用户数据目录。需要系统已有 Microsoft Edge WebView2 运行时。
